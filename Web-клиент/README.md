# Web Client модуль системы массовых опросов и тестирования

Разработчик:viivevv 
Технологии: Node.js + Express, Redis (сессии), JWT (авторизация)

## Описание

Web Client — веб-интерфейс платформы для проведения массовых опросов и тестирования.  

Модуль обеспечивает:
- Доступ через браузер
- Аутентификацию через внешние сервисы (GitHub, Yandex ID) или одноразовый код
- Управление сессиями через Redis
- Автоматическое обновление access-токена (refresh)
- Проксирование запросов авторизованного пользователя к Главному модулю
- Горизонтальное масштабирование (можно запустить несколько экземпляров)

Модуль полностью соответствует требованиям проекта по сценариям аутентификации и авторизации.

## Функциональность

### Статусы пользователя
- Неизвестный — показывается страница входа
- Анонимный — после начала авторизации (ожидание подтверждения)
- Авторизованный — доступ к личному кабинету и действиям

### Маршруты
- / — главная страница (логика статусов)
- /login?type=... — начало авторизации (создание сессии Anonymous)
- /logout — выход из системы
- /api/* — прокси к Главному модулю с accessToken и refresh
- /debug/auth-success — временный маршрут для теста Authorized (удалить перед защитой)

## Запуск локально

1. Установите зависимости:
  
   npm install
   
2. Запустите Redis (например, redis-server.exe из порта для Windows или Docker).

3. Запустите сервер:
  
   node app.js
   
4. Откройте в браузере: http://localhost:3000

### Тестирование потока
1. На главной — выбрать способ входа
2. Перейти по /debug/auth-success (имитация подтверждения)
3. Обновить главную — личный кабинет
4. Выйти — возврат на страницу входа

## Технологии

- Node.js + Express — сервер и роутинг
- Redis — хранение сессий (sessionToken → данные)
- cookie-parser — работа с cookie
- uuid — генерация токенов
- axios — запросы к другим модулям
- dotenv — переменные окружения

## Горизонтальное масштабирование

Модуль stateless (сессии в Redis), поэтому поддерживает горизонтальное масштабирование:
- Запустите несколько экземпляров node app.js на разных портах
- Используйте NGINX как reverse-proxy и load balancer
