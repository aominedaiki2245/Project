Python  
Docker  
Telegram  
Статус сборки  
📖 Обзор  
Этот репозиторий содержит модуль Telegram Bot для масштабируемого группового проекта, направленного на создание приложения для проведения массовых опросов и тестирования. Бот выступает в роли клиента Telegram, интегрируясь с другими модулями (Core Logic, Authentication и Web Client) для обеспечения бесперебойного взаимодействия с пользователями.
Ключевые особенности:

Аутентификация пользователей через OAuth (GitHub, Yandex ID) или код.  
Управление сессиями с использованием Redis.  
Обработка команд для статуса системы, сервисов и будущих функций тестирования.  
Циклические проверки статуса входа и уведомлений.  

Проект соответствует указанным сценариям потока задач, обеспечивая правильную обработку состояний пользователя: Неизвестный, Анонимный и Авторизованный.  
Этот бот является частью более крупной системы, предназначенной для горизонтального масштабирования, развертываемой через Docker.  
🚀 Возможности

Аутентификация: Безопасный вход/выход с JWT-токенами и механизмами обновления.
Команды:
/start: Приветственное сообщение и обзор системы.
/login [type]: Инициация аутентификации (github, yandex, code).
/logout [all=true]: Выход из текущего или всех устройств.
/status: Статус системы и статистика.
/services: Детальная информация о сервисах.
/help: Справочник по командам.
/test: Пример авторизованной команды (расширяемая для тестов).

Фоновые задачи: Опрос для завершения входа и уведомлений пользователей.
Интеграция: Вызовы API к Core (порт 8082) и Auth (порт 8081) сервисам.
Мониторинг: Проверки здоровья системы в реальном времени.

Будущие улучшения:

Создание и прохождение тестов.
Управление личным профилем.
Уведомления в реальном времени.

📦 Установка
Предварительные требования

Установленные Docker и Docker Compose.
Токен Telegram Bot (получите от BotFather).

Шаги

Клонируйте репозиторий:textgit clone https://github.com/your-username/telegram-bot-branch.git
cd telegram-bot-branch
Создайте файл .env в корневой директории:textTELEGRAM_BOT_TOKEN=your_bot_token_here
Соберите и запустите с помощью Docker Compose:textdocker-compose up --buildЭто запустит бот, Redis, базы данных и заглушки для сервисов Auth/Core/Web.
Для локальной разработки (без Docker):
Установите зависимости: pip install -r requirements.txt
Установите переменные окружения.
Запустите: python bot.py
